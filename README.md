# MeetPoint

Онлайн-платформа для записи на мероприятия с незнакомыми людьми для общения и нетворкинга

## Backend

Стек технологий: Java, Spring Boot, Spring Security, Spring Cloud, PostgreSQL, MiniO, Redis, JPA,
Liquibase, RabbitMQ, Kafka, Docker, JUnit, Mockito, Testcontainers, Swagger, Gradle, Grafana, Prometheus

Основные задачи:

- Авторизация, аутентификация, управлением профилем пользователя.
- Просмотр различных мероприятий, запись на них.
- Персонализированные рекомендации мероприятий.
- Напоминание о записях на мероприятия на почту и/или в Telegram.
- Сбор метрик.
